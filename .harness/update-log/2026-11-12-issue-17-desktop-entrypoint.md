# Claude 桌面会话的 CLI 判别

按 2026-11-12 Issue #17 的确认变更，
[运行审查方](../workflows/decision-review.md#运行审查方)仅在两种 Claude 桌面入口下采用
`CLAUDE_CODE_EXECPATH`；它在 VS Code 扩展和其他 Claude 会话中同样存在，不能单独证明桌面来源。
桌面入口采用的可执行文件版本不可读时拒绝，不回退；非桌面会话继续按 app 目录、扩展、PATH 选择。
下游采用时同步脚本和说明；离线回归覆盖入口判别，版本顺序与路径顺序相反的候选，以及非空旧档位。
入门文档已同步四层发现顺序。实机 smoke 证据与是否补跑由交付 PR 的评审记录说明。

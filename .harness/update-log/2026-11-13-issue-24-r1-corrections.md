# Codex B MCP 禁用与回归修正

Issue #24 的 R1 F-001～F-003 修正由[运行审查方](../workflows/decision-review.md#运行审查方)维护。
空表覆盖不会删除 Codex 按层合并的已配置服务器。入口在能力检查后、日志和模型调用前，
以 B 的清除后环境和实际工作目录执行 `mcp list --json`，逐服务器设置 `enabled=false` 后再复查。
命令失败、列表结构不符、名称不匹配 `^[A-Za-z0-9_-]+$`（包括带点名称），或仍有启用项时退出 2。
该机制依赖 CLI 的列表输出及名称寻址；不使用 `--ignore-user-config`，不改用户配置或配置目录。
CLI `0.167.0-alpha.4.1` 首次枚举会向 HTTP MCP 探测 OAuth 元数据；回环探针证实逐项禁用后的
复查与 `exec` 不连接这些服务器，但不能把整个预检称为无网络请求。

下游采用时一并更新入口、回归和文档。测试的临时目录输入固定含冗余路径组件，保证移除规范化后，
轻量断言在 TMPDIR 未设置、无末尾斜杠、有末尾斜杠时均能检出回退，不在通用入口或 CI 重跑整套回归。
Codex B 使用 `--ephemeral`，排查查本场事件流、stderr 和输出，不依赖 resume。
两种预算模式的回环 CLI 探针、假 CLI 故障用例和定向变异证据由交付 PR 保存。

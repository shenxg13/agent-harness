# 评审收敛记录必须为单一 JSON 对象

评审记录校验器此前直接依赖 jq `-e` 的退出码，可能误放行空输入或多条记录。
本次从下游回流通用修复，来源和取舍见[来源记录](../../docs/provenance.md#评审记录校验修复回流)。

- `scripts/github/review_convergence.sh` 在运行规则前显式检查输入恰好包含一个 JSON 对象，
  并检查规则输出同样恰好包含一个对象；失败保留 `review convergence record is invalid` 前缀。
- `scripts/tests/test_review_convergence.sh` 覆盖空文件、空白、非 JSON、非对象、
  多条记录和替身过滤器无输出，断言成功输出 `OK:`、失败不输出 `OK:`，保留原有协议用例。
- 下游采用时同步上述两个脚本；已采用同一修复的项目可核对后从本地定制清单移除此项。
  此前误判成功的非法输入会开始失败，合法记录（含末尾换行）仍通过。

规则过滤器、评审协议和 jq 最低版本不变。本项修复工具对既有契约的执行，
不改变长期有效的项目事实，因此不更新 `.project-wiki/` 或新增知识日志。
